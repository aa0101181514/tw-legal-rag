# Remote MCP Anchor Search Bundle

As of 2026-06-04, the hosted Remote MCP endpoint at `https://tlr.dr-lawbot.com/mcp` uses an anchor-style response for `search_judgments`.

This applies to the hosted MCP tool surface. The open-source CLI remains retrieval-only and still uses TLR as a remote retrieval endpoint.

## What changed

`search_judgments` now returns an anchor bundle in the Remote MCP flow. The server reads the most relevant judgment excerpts first and returns:

- `allowed_citations`: citation IDs that may be used as authority.
- `judgments`: judgments whose reasoning excerpt was actually included in this response.
- `unread_candidates`: candidates not included because of payload budget or unavailable full text.
- `verification_instructions`: rules telling the downstream AI to cite only `allowed_citations`.

Only judgments listed in `allowed_citations` should be cited for court reasoning.

## Why

The previous listing-only flow made it too easy for a downstream AI to cite a real Taiwan case number while inventing or misattributing the legal proposition attached to that case. The anchor bundle reduces this title-only mis-citation risk by giving the AI read excerpts, not just titles.

The server still does not call an LLM. It only performs retrieval and packaging. Any answer is generated by the user's own AI tool.

## Important limits

This is not a guarantee that the downstream AI will be faithful. TLR cannot control Claude, ChatGPT, Gemini, or local models after retrieval. The anchor bundle reduces title-only mis-citation risk, but users should still review cited judgments.

`unread_candidates` are not authority. They are included only as retrieval metadata and must not be cited as court reasoning.

## Relationship to CLI bundles

The CLI `pack` command already packages judgments and citation rules for user-provided AI tools. The hosted MCP anchor flow applies the same retrieval-only philosophy directly to Remote MCP `search_judgments`, with a stricter read whitelist: `allowed_citations` contains only judgments whose excerpts were actually included in that MCP response.
