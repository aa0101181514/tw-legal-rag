# AI で台湾の判決を検索する（ユーザーガイド）

法律偵探（Legal Detective）の判決検索サービス（TLR）を使うと、2,200 万件の
台湾裁判文書を**あなた自身の AI**（ChatGPT / Claude / 開発ツール）で検索・引用
できます。プログラミングも API キーも不要です。

> ⚠️ 重要：本サービスは「判決を見つけて提供する」ことだけを担います。**回答は
> あなた自身の AI が生成するものであり、法律偵探は AI の回答内容を保証しません。**
> 法的な結論は必ず判決リンクを開き、全文を自分で確認してください。これは法的助言
> ではありません。

---

## 方法 A：Claude Desktop（最推奨、インストール不要）

1. **Claude Desktop** アプリを開く。
2. 左上メニュー → **Customize（カスタマイズ）** → **Connectors（コネクタ）**。
3. 右上の **+** → **Add custom connector（カスタムコネクタを追加）**。
4. 以下を入力：
   - **Name（名前）**：`法律偵探`（任意）
   - **Remote MCP server URL**：`https://tlr.dr-legal.com.tw/mcp`
5. **Add** を押す。これで完了 — OAuth 設定も API キーも不要です。

その後は自然言語でそのまま質問できます（台湾判例は中国語での質問が最も効果的）。
例：

> 銀行法違反で無罪となった判決を探して、事件番号を 3 つ引用してください。

Claude が自動的に判決データベースを検索し、関連判決を読み込んだうえで自身の理解に
基づいて回答し、クリック可能な判決リンクを付けます。

---

## 方法 B：ChatGPT（カスタム GPT を作成）

1. ChatGPT で **Custom GPT** を作成（ChatGPT Plus が必要）。
2. 編集 → **Actions** → **Create new action** → **Import from URL**。
3. 以下を貼り付け：`https://tlr.dr-legal.com.tw/openapi.yaml`
4. **Authentication（認証）** は **None** を選択。
5. 保存後、その GPT 内で質問すれば、判決検索が自動的に呼び出されます。

---

## 方法 C：コマンドライン（開発者・上級者向け）

ターミナルに慣れているなら、オープンソース CLI をインストールし、判決をファイルに
パックして任意の AI に貼り付けられます：

```bash
pip3 install twlegalrag

# 判決リストを検索
twlegalrag search "銀行法 無罪" -n 5

# バンドルにパック（自分の AI 用）
twlegalrag pack "違反銀行法被判無罪的案件" -o bundle.json
```

`bundle.json` を丸ごと ChatGPT / Claude に貼り付け、「バンドル内の判決のみを
引用する」よう指示してください。

## よくある質問

**Q：特定の事件番号を直接調べられますか？**
A：できます（v1.1）。完全な文書番号（例：「最高法院112年度台上字第9號」）を
そのまま入力すると、その事件番号のデータベース内文書が正確に取り出されます
（同一番号の民事・刑事事件は並記してラベル表示）。**「該当事件番号なし」と
返ってきた場合、それはデータベースに未収録という意味であり、その裁判が存在しない
という意味ではありません — このとき AI に記憶で事件を語らせないでください。**

**Q：ある判決が上級審で破棄されたか、確定したかはどう分かりますか？**
A：判決全文を読む際に「審級関係」（case_history）が付属します。データベースに
記録された上級・下級の裁判が一覧され、上級審に破棄された判決には「主文に『廢棄』
（破棄）を含む」フラグが付きます — その判決の判示はすでに覆されており、AI は
現行有効な見解として引用すべきではありません。注意：**上級審の記録がないことは
データベース未収録を意味するだけで、判決の確定を意味しません。**

**Q：AI が判決を引用しました。裁判所の判示を読み違えていないことをどう確認
すれば？**
A：v1.1 以降、すべてのバンドルに「見解レイヤーのセルフチェック」指示が内蔵され、
AI は回答後に、判示が確かにその判決に由来すること、勝敗・破棄の方向が逆転して
いないこと、破棄済み判決を有効な見解として扱っていないことを確認するよう義務付け
られています。ただしこれも**ベストエフォート**です — 最終的には必ず自分で判決
リンクを開き、主文と理由を確認してください。特に実際に使う結論については。

**Q：「銀行法の無罪判決」を頼んだのに、有罪や民事の事件が出てきました。**
A：検索は「意味的に関連するものを見つける」のであって「結果を精密に絞り込む」
ものではありません。AI はリストを受け取った後に全文を読んで判断しますが、
**必ず自分で判決リンクを開いて確認してください** — 特に「無罪かどうか」のような
結論は判決主文を読むべきで、AI の要約だけを信じてはいけません。

**Q：私の質問は記録されますか？**
A：検索文字列は検索サービスに送信され、検索品質改善のため記録されることが
あります（個人身元とは紐付けず、生成モデルの学習にも使いません）。**クエリに
個人の機密や秘匿すべき事実を入力しないでください。**

**Q：料金はかかりますか？**
A：判決検索は無料・登録不要です。AI の利用料はあなた自身の ChatGPT / Claude
アカウントの負担です — 本サービスは AI 利用料を請求せず、あなたの代わりに AI を
呼び出すこともありません。

**Q：判決リンクが開けない／完全な判決文が読みたい。**
A：各結果には `dr-legal.com.tw` の判決リンクが付いています。開けば全文を読めます。
